# FreshSave

This project is an HTML5 and CSS web application. Do not add a JavaScript framework, JavaScript application code, package manager, or build tool unless the project requirements change.

- Open `index.html` in a browser to view the site.
- See `README.md` for optional local-server instructions.
- Shared page styling lives in `css/style.css`.
- Keep links and asset paths relative so pages work when opened directly from disk.
