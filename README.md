# FreshSave

FreshSave is built with HTML and CSS. It does not need React, Node.js, npm, pnpm, or Vite.

## Run it

**Quickest:** Open `index.html` in a web browser. Use the side navigation to visit the other pages.

**Optional local web server:** Open PowerShell in this folder and run:

```powershell
py -m http.server 8000
```

Then visit <http://localhost:8000>. Press `Ctrl+C` in PowerShell to stop the server.

## About FreshSave

The pages include the food inventory, rescue listings, reservations, account settings, and impact views.
